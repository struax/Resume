# Steven Truax Cybersecurity Portfolio

A simple static HTML/CSS portfolio designed for GitHub Pages and `steventruax.com`.

## Files
- `index.html` — website content
- `style.css` — responsive dark theme and layout

## Before publishing
1. In `index.html`, replace `REPLACE-WITH-YOUR-EMAIL` with your public professional email address.
2. Replace the LinkedIn placeholder link (`href="#"`) with your LinkedIn profile URL.
3. Add a resume PDF link after uploading a public-safe PDF to this repository (or add a Resume section/link).
4. Replace the sample project cards with actual completed projects and links. Do not claim projects are completed until they are.
5. Review all text for accuracy and remove anything confidential or proprietary.

## Publish with GitHub Pages
1. Open https://github.com/struax/Resume while signed in.
2. Select **Add file → Upload files** and upload `index.html` and `style.css` to the repository root.
3. Commit the changes.
4. Open **Settings → Pages** and check the current publishing source. If Pages is already publishing this repository, wait for the deployment and open the site URL.
5. If Pages is not enabled, under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Under **Custom domain**, enter `steventruax.com` only if this repository is intended to host that domain. Do not change DNS records unless you know which records currently serve the domain; preserve the existing configuration.
7. Ensure HTTPS is enabled when GitHub reports the certificate is ready.

GitHub Pages documentation:
- https://docs.github.com/en/pages/quickstart
- https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

## Notes
This is a static site; no build tools or JavaScript frameworks are required. The content is a starter draft and should be reviewed before publishing.
